# Before You Begin

Before deploying your React website, make sure your computer has the required software and that you have the necessary accounts.

## Required Accounts

You will need:

- a GitHub account
- a Vercel account

You can create these accounts before starting the deployment process.

## Required Software

Make sure the following software is installed:

- Node.js
- npm
- Git
- a code editor such as Visual Studio Code
- a modern web browser
- PowerShell or another terminal

## Verify Node.js

Open PowerShell and run:

```bash
node --version
```
